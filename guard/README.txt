Critical Guard: closes TikTok in Chrome from 4:45 until today's Critical plan is done

Install (one time, about 1 minute):
1. Unzip this folder somewhere it will stay, e.g. Documents\Critical Guard. Don't delete it afterwards: Chrome runs the extension from this folder.
2. In Chrome, go to chrome://extensions
3. Turn on "Developer mode" (top right).
4. Click "Load unpacked" and choose the Critical Guard folder (the one with manifest.json in it).
5. Click the jigsaw icon next to the address bar and pin Critical Guard so you can see the "ON" badge.

It starts in "Until today's plan is done" mode: from 4:45 pm on school days, any TikTok tab closes straight away. When you finish today's plan in Critical (open in Chrome), Critical tells Critical Guard and TikTok opens back up until tomorrow. Click the shield icon to change the time, the days, or switch to Always / Fixed hours. Making it looser takes 2 minutes to kick in.

If you did your plan somewhere else (phone or Critical Browser), open Critical in Chrome once so it can sync and tell Critical Guard.
